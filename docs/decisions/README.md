# Decisões de arquitetura

Registre aqui as decisões que alteram arquitetura, segurança, persistência, contratos públicos ou regras de domínio.

Use arquivos no formato `ADR-0001-titulo-curto.md`, com esta estrutura:

```markdown
# ADR-0001 — Título

## Contexto

## Decisão

## Consequências

## Alternativas consideradas

## Referências
```

Uma decisão aprovada não deve ser reescrita para esconder o histórico. Caso seja substituída, crie uma nova ADR citando a anterior.
